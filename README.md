# Pangasinan Heritage Digital Showcase

## Student Name

Jomar John Punzal

## Selected Framework

React with Next.js 14 (App Router)

## Project Description

The Pangasinan Heritage Digital Showcase is a responsive website
that presents historical places and tourist destinations in Pangasinan.

The website uses a component-based Atomic Design structure and
Static Site Generation for improved performance and deployment.
